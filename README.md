# 강북구 철거업체 | 정적 홈페이지 (수정본 v2)

**공식 사이트명: `강북구 철거업체`**. 사용자 요청에 따라 홈페이지 헤더, 워드마크 로고, SEO 메타 태그, Open Graph, JSON-LD `WebSite.name` 및 화면 내 대표 명칭을 통일했습니다. 페이지 본문에서는 업체 브랜드명을 반복하지 않습니다. 실제 서비스 제공자 오인을 방지하기 위해 하단 푸터에만 `서비스 제공: 점포리턴`을 남겼으며, 구조화 데이터의 `Organization.name`에도 업체명을 사실대로 유지했습니다.

HTML5/CSS3 정적 사이트이므로 유료 API·DB·빌드 단계가 필요하지 않습니다. **이 ZIP은 로컬 제작물이며 아직 공개 서버에 배포하지 않았습니다.**

## 파일 구조

- `index.html` — 단일 페이지; SEO Title/Description/H1, 본문, 상담 버튼 4개, 시공 사진 두 쌍, 실적, FAQ, JSON-LD
- `style.css` — 화면 폭에 따라 대응하는 반응형 디자인. 상단 고정 헤더와 상담 CTA 포함
- `assets/hero*.webp`, `assets/service*.webp` — 철거·원상복구 설명용 **생성 이미지** (실제 시공 증빙 아님)
- `assets/real-case-*.webp` — 사용자가 제공한 실제 작업 전후 사진 2쌍
- `assets/og-gangbuk-demolition.webp` — 공유 이미지 (브랜드명 삭제, 사이트명 통일)
- `assets/logo.svg`, `assets/mark.svg`, `favicon.ico`, `favicon.png` — 로고/파비콘
- `robots.txt`, `sitemap.xml` — 검색엔진 수집 안내
- `.nojekyll` — GitHub에서 소스 관리 시 사용해도 무해한 빈 파일

## 도메인 확정 및 배포 전 URL 점검

사용자가 선택한 주소는 **`https://gangbuk-demolition-guide.github.io/`** 입니다. 검색엔진 정보를 포함한 절대 URL은 현재 이 주소로 작성되어 있습니다. 그러나 사이트가 해당 주소에서 실제로 열리는지 검증되지 않았습니다.

**중요:** GitHub Pages는 영업을 주 목적으로 하는 무료 상업 사이트 호스팅에 제한이 있습니다. 철거 견적 유도 사이트는 GitHub에서 파일을 관리하되 **실제 공개는 해당 용도가 허용되는 Netlify Free 등 적합한 정적 호스팅 서비스를 선택**하는 방식을 권장합니다. GitHub Pages 공개 기능 사용을 전제로 제작하거나 이용 약관 준수를 보장한 것은 아닙니다.

실제 공개 주소가 다른 경우 **배포 전에** `index.html`, `robots.txt`, `sitemap.xml` 파일에서 다음 문구를 일괄 교체하세요.

`https://gangbuk-demolition-guide.github.io/` → `https://실제-공개-도메인/`

이렇게 하면 canonical, og:url, og:image, 파비콘 절대 URL, WebSite/WebPage/Organization/Service 스키마 URL·@id, robots.txt 사이트맵 URL, sitemap.xml loc 값이 모두 같은 공개 주소를 사용하게 됩니다. `index.html` 파일 링크의 `href="/"`는 **도메인 루트**에 배포하는 경우에만 적합합니다. 하위 디렉터리 형태의 프로젝트 사이트로 배포하는 경우에는 사이트명 지원과 상대 경로 등을 별도 검토해야 합니다.

### GitHub 소스 저장소에 업로드하는 방법

1. 선택한 조직 또는 계정의 저장소를 준비합니다.
2. ZIP 압축을 해제하여 **`index.html`이 최상단에 있도록** 파일을 올립니다.
3. GitHub Pages 공개 기능은 활성화하지 않고, 지원되는 정적 호스팅에서 저장소를 연결하거나 정적 파일 폴더 전체를 수동 업로드합니다.
4. 호스팅에서 발급된 실제 공개 URL에 맞춰 위 주소 3곳의 참조를 수정하고 재배포합니다.

## 이번 수정의 핵심 사항

- 사이트명: **강북구 철거업체**로 일관 적용
- `title`: `강북구 철거업체 | 폐업철거·상가철거·원상복구 견적 상담`
- H1: `강북구 철거업체, 폐업철거부터 상가 원상복구까지` (한 개)
- meta description: 수유동·미아동·번동·우이동, 폐업철거·상가철거·원상복구, 견적 판단 요소가 자연스럽게 포함되도록 변경
- 접근 가능한 상단 고정 헤더에 **견적 상담 버튼** 추가, 모바일에서도 표시
- 총 상담 CTA **4곳**: 헤더, 히어로, 철거비용, 하단
- 모든 CTA 동일한 사용자 지정 Google Forms URL로 연결. 외부 링크는 `target="_blank" rel="noopener noreferrer"`
- 점포리턴 상세페이지 백링크는 하단에 **1회**
- 실적: 폐업·철거 5,540건 이상 / 학원·카페·식당 2,190건 / 상가·병원 1,850건 / 정부지원금 누적 상담 4,860건 이상
- 강북구 실적이라는 잘못된 단정은 하지 않음
- 실제 시공 전후 사진: `01-before`↔`01-after`, `02-before`↔`02-after`; 원본 장면 변경하지 않음
- `WebSite`, `Organization`, `WebPage`, `Service` JSON-LD; canonical, og:site_name, robots(index/follow), favicon, sitemap 등 정적 SEO 적용
- 마감된 2026년 희망리턴패키지 접수를 진행 중인 사업처럼 홍보하지 않음

## 공개 후 SEO 절차 및 점검

1. 실제 홈페이지/이미지/robots.txt/sitemap.xml이 HTTPS로 열리고 HTTP 상태 코드가 200인지 확인합니다.
2. robots.txt에서 수집이 막히지 않았는지, HTML에 `noindex`가 없는지 확인합니다.
3. 네이버 서치어드바이저에 **실제 공개 주소를 등록하고 소유 확인**한 뒤 사이트맵 URL을 제출합니다. 필요할 경우 페이지 수집을 요청합니다.
4. 구글 서치 콘솔에서도 소유 확인 및 사이트맵 제출, URL 검사, 색인 현황 점검을 합니다.
5. 사이트명 노출은 검색엔진의 자동 판단 결과입니다. **일반 키워드형 사이트명은 고유 상호·브랜드명보다 검색엔진이 채택하지 않을 수 있으며, SEO 적용만으로 상위 노출을 보장하지 않습니다.**
6. 사이트가 장기 운영된다면 이용자에게 유용한 지역별 공사 조건 및 정확한 사례 정보를 꾸준히 보강하되 복제 페이지의 대량 생산은 피합니다.
